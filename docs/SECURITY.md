# 安全模型

## 信任边界

墨隐默认信任当前设备和运行用户，不信任待发送的目标系统。浏览器版本不发起上传请求，CLI 只读取用户指定的本地路径并写入明确的输出位置。

项目不提供云端扫描 API，也不需要账户、数据库或遥测服务。

## 数据处理

- 普通 `ScanReport` 包含命中的原文，便于即时人工复核，不应作为公开 CI artifact。
- 批处理汇总只记录每个文件的数量和判定，不记录敏感原文。
- `PrivacyInventory` 和 `PrivacyDriftReport` 只保存带盐匿名指纹、风险和数量。
- 网页刷新或关闭后不会由墨隐持久化输入。
- CLI 不会修改输入文件；目录模式写入新的安全副本目录。

## 盐值与匿名标识

一致化替换和隐私基线依赖调用者提供的盐值。它们的目标是限制关联范围，而不是提供密码学不可逆保证。

建议：

- 每个仓库或数据域使用不同的随机盐值；
- 在 CI 中通过 Secret 注入；
- 不把盐值、原文报告或真实生产样本提交到 Git；
- 盐值泄露后更换盐值并重新建立基线。

## 已知限制

- 规则可能误报，也可能漏掉私有格式或经过编码、压缩、加密的数据。
- 自定义敏感词为精确字面匹配，不处理同义词和语义推断。
- 访问凭据规则只能覆盖常见前缀、键值形式、JWT、URL 凭据和 PEM 私钥头。
- 生成的脱敏文本仍可能通过上下文间接识别个人。
- 本项目不能替代组织的数据分类、法律评估和人工审批。

## 安全报告

请使用 GitHub 仓库的 Security Advisory 私下报告可导致敏感数据泄露、错误覆盖文件或绕过高风险检测的问题。报告中请使用虚构样本，不要粘贴真实密钥或个人信息。

普通误报、规则建议和兼容性问题可通过 Issue 提交。
