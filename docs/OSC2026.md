# OSC 2026 参赛准备

目标组别：MoonBit 开源创新赛 2026，8 月 24 日报名节点。

## 需求对应

| 赛事关注项 | 当前实现 |
| --- | --- |
| MoonBit 为主要实现语言 | 检测、校验、替换、配置、清单和漂移策略均为 MoonBit |
| 公开代码仓库 | `github.com/zcyyyyyyy-yy/moyin` |
| 清晰 README | 问题、快速启动、CLI、架构、测试和限制均已说明 |
| 可运行示例 | `examples/sample.log`，网页内置虚构样本 |
| 自动化测试 | 49 项 MoonBit 测试、CLI 集成测试、浏览器冒烟测试 |
| 持续集成 | `.github/workflows/ci.yml` |
| 工程质量 | 格式检查、接口生成、性能基准、覆盖率和发布文件验证 |
| Mooncakes 发布 | 模块元数据已准备；需仓库所有者登录后执行正式发布 |

赛事页面将 4,000–10,000 行有效 MoonBit 代码作为参考规模，代码质量、完整性和真实价值同样重要。项目不通过复制或空壳文件凑行数；后续新增代码需对应规则、性能、平台集成或可验证测试。

官方要求页面：<https://moonbitlang.github.io/OSC2026/index.html#requirements>

## 项目亮点

1. 浏览器与 CLI 共用一份 MoonBit 引擎，全部离线。
2. 身份证校验位、Luhn 和网络格式校验降低普通正则的误报。
3. 策略化规则、自定义词、分块扫描和冲突消解支持真实工程输入。
4. 带盐匿名标识保留数据关联关系，同时缩小跨项目关联范围。
5. 隐私基线不保存原文，可用于 Pull Request 或发布流水线门禁。
6. 报告明确说明风险、位置、原因和是否建议阻止外发。

## 建议演示流程

1. 打开网页，载入内置示例并展示数据不离开浏览器。
2. 展开高级策略，禁用低风险规则并加入自定义项目代号。
3. 切换一致化替换，展示同一手机号得到相同匿名标识。
4. 下载脱敏文本与 JSON 报告。
5. 在终端执行目录批处理。
6. 使用 `--baseline` 和 `--fail-on-drift` 展示新增手机号导致 CI 失败。
7. 展示 GitHub Actions、49 项测试、基准结果和 MoonBit 公共接口。

## 报名前剩余事项

- 在 Mooncakes.io 注册或登录并执行 `moon publish`；
- 等 GitHub Actions 首次运行通过后保留截图；
- 录制 2–3 分钟演示视频；
- 准备项目中文简介、架构图、实际使用场景和后续路线；
- 使用公开虚构样本完成最终复测；
- 确认赛事报名表、截止时区和仓库公开状态。
